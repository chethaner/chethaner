## `> ls -la /projects`

### 🔍 ConflictRAG — RAG-Based Conflict Analysis System

A **Retrieval-Augmented Generation (RAG)** system for analyzing conflicts and geopolitical events using AI. Processes large document corpora and surfaces contextually grounded insights using LLMs and vector search.

```
 document corpus        RAG pipeline             LLM layer
┌──────────────────┐   ┌──────────────────┐   ┌──────────────────┐
│  PDF / text docs │   │  vector indexing │   │  grounded        │
│  web scraping    │──►│  chunking &      │──►│  generation with │
│  structured data │   │  retrieval       │   │  source citation │
└──────────────────┘   └──────────────────┘   └──────────────────┘
```
